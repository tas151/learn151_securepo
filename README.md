# learn151_securepo
# インフラ実務3年目のセキュリティ検証ナレッジベース（ポートフォリオ）

インフラエンジニアとしての「Linux大規模構築・運用保守」の実務経験をベースに、
ペネトレーションテスト（侵入・権限昇格）および Web アプリケーション脆弱性の仕組みを自学・検証したメモ集です。
単なる自動ツールの実行（ボタンを押すだけ）に留まらず、
「裏側でどのようなコマンドが動いているのか」「どのようなHTTP通信が行われているのか」を
基礎からひとつずつ確認し、これまでに学習した内容を備忘録として書き留めています  

※本リポジトリは診断の実務経験ではなく、
TryHackMe・PortSwigger・脆弱性調査などを通じて自学した内容を整理した学習ログです。


---

## 検証・学習コンテンツの構成

CTF と Web 診断では求められるアウトプットが異なるため、目的に応じて最適なレポート形式を使い分けています。  
これは実務でも同様で、  
- CTF系の演習 → 攻撃手順の記録  
- Web診断 → 脆弱性単位のレポート  
と形式が異なります。

そのため、レポート形式が異なることは自然であり、  
**むしろ目的に応じて書き分けられている点が強みであると考えています。**

## 1. ペネトレーションテスト & CTF ライトアップ  
実戦形式でのネットワーク侵入、サービス特定、Linux特権昇格までのプロセスを思考ごとに記録したコマンドチートシートです。

- [SimpleCTF](/writeups/SimpleCTF)  
  - Nmap によるサービス特定、CMS の脆弱性を突いた侵入、一般ユーザーから root への Privilege Escalation の記録。

---

## 2. Webアプリケーション脆弱性（検証ノート）  
ブラウザとサーバー間の HTTP リクエスト/レスポンス、プログラム側の原因、および根本対策（インフラ層・開発層）を体系化するための検証メモです。

- [SQL Injection](/OWASP%20TOP%2010/SQL%20Injection)  
  - Unionベース、エラーベース、ブラインド等の検知挙動と、プリペアドステートメントによる根本対策の整理。

- **[現在進行中] Cross-Site Scripting (XSS)**  
  - 7月下旬完了目標。反射型・格納型XSSの挙動とエスケープ処理の検証。

- **[次ステップ] CSRF,IDOR / Access Control**  
  - 8月中旬着手予定。認可制御の不備に関する検証。

現時点では SQL Injection と XSS を中心に検証していますが、これらは Web 脆弱性の基礎であり、  
今後は Access Control、IDOR、CSRF、CSP など実務で頻出する領域へ順次拡張していく予定です。

---

## セキュリティ運用（脆弱性管理）経験

大規模インフラ運用保守の中で、週次で JPCERT/CC からの脆弱性情報を確認し、  
自社環境が該当するかどうかを以下の観点から評価していました。

- 対象アプリケーションのバージョン  
- 攻撃元が到達可能か（ネットワーク構成）  
- サーバが置かれている環境のセキュリティレベル  
- 実際に攻撃が成立するかどうかの可否判断  

結果として、クローズド環境や到達不能な構成により  
「影響なし」と判断し報告する業務を担当していました。

この経験により、  
**脆弱性情報の読み解き、影響範囲の判断、環境依存のリスク評価**を実務として経験しています。
